funcy_pipe.funcy_extensions.dig(path, data, *, default=None)[source]#

Dig into nested dict using dot-path string or list of keys. Raises KeyError/TypeError if path missing and no default.

>>> dig('a.b', {'a': {'b': 1}})
1
>>> dig('a.b', {'a': {'b': 1}}, default=42)
1
>>> dig('a.x', {'a': {'b': 1}}, default=42)
42
>>> dig('a.x', {'a': {'b': 1}})
Traceback (most recent call last):
...
KeyError: 'x'
>>> dig(['a', 'b'], {'a': {'b': 1}})
1
